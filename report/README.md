# Report

The final LaTeX report source is `main.tex`.

Build the PDF with:

```bash
pdflatex -interaction=nonstopmode -halt-on-error -output-directory report report/main.tex
pdflatex -interaction=nonstopmode -halt-on-error -output-directory report report/main.tex
```

Compiled output:

```text
report/main.pdf
```
